# 微光｜長輩友善讀經筆記

## 功能
- 大字體、高對比、按鈕較大，手機與桌面皆可使用。
- 直接用選單選擇聖經書卷及常用經節，不必輸入經文範圍。
- 一鍵生成有實際內容的筆記：經文、釋義方向、反思問題、禱告、行動及晚間回顧。
- 引導式讀經，一次一題，共五步。
- 可編輯、儲存、複製、列印／存成 PDF、匯入匯出 JSON 備份。
- 不需 API Key。內建經文與內容可直接使用；不是即時 AI 回答。

## GitHub Pages 部署
1. 將 `index.html` 和 `README.md` 上傳至 GitHub repository 根目錄。
2. 開啟 Settings → Pages。
3. 選擇 Deploy from a branch，Branch 選 `main`，資料夾選 `/(root)`，按 Save。
4. 等待部署完成，使用 GitHub Pages 顯示的網址開啟。

## 注意
內建經文是常用經節的文字及靈修摘要。不同中文聖經譯本文字可能不同，請以手邊正式聖經為準。若要擴充完整聖經搜尋，請使用有合法授權的聖經文本或 API，並標示譯本與來源。
筆記儲存在目前瀏覽器的 localStorage，不會自動同步到其他裝置，請定期匯出 JSON 備份。
